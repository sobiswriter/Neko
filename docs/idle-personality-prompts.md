# Idle personality: exact ImageGen prompts

Built-in ImageGen was used with transparent background and `assets/neko-idle-v3.png` as identity reference. Corrections reference the preceding draft. Accepted sources are `assets/neko-idleplay-a-v1.png`, `assets/neko-idleplay-b-v1.png` and `assets/neko-idleplay-c-v1.png`. The bottom eight swish candidates in B are excluded because their registration/proportions drifted; the existing verified swish instead gains a canonical blink. Source alpha was checked on the saved PNGs, independently of the tool preview. No anatomy pixels were painted or patched programmatically.
